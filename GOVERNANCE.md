# Governance

`jev-mcp` currently uses a lightweight maintainer-led governance model.

## Maintainer

The repository owner, [@Afloat16](https://github.com/Afloat16), is the current
maintainer and has final responsibility for merges, releases, repository
settings, and project direction.

## Contributions

Contributions are evaluated on:

- correctness and maintainability;
- preservation of the conservative Jev authority model;
- privacy and credential safety;
- compatibility with the supported MCP interface;
- tests and documentation appropriate to the change;
- project scope.

A proposal is not guaranteed to merge solely because it is technically
possible.

## Becoming a maintainer

If the contributor community grows, maintainership may be extended to people
with a sustained record of high-quality reviews, implementation work, security
awareness, and constructive project participation.

Changes to governance should be made publicly through a pull request.

## Decision transparency

Material behavior changes should be documented in the changelog and, where
needed, migration notes. Security-sensitive details may be coordinated
privately until a fix is available.
