# Support

This is a community-maintained project with no guaranteed support SLA.

## Questions and usage problems

1. Read the [Quick start](docs/QUICKSTART.md).
2. Check [Troubleshooting](docs/TROUBLESHOOTING.md).
3. Check the [FAQ](docs/FAQ.md).
4. If the problem is reproducible in `jev-mcp`, open a GitHub issue using the
   provided template.

Keep public reports minimal and redacted. Do not post credentials, `.env`
files, private source code, customer data, or raw sensitive production logs.

## TypeSafe account / billing / service availability

Those are provider-side concerns rather than `jev-mcp` repository support.
Use the official TypeSafe support/documentation channels for provider-account
issues.

## Security reports

Do not open a normal public bug report for a vulnerability containing sensitive
details. Follow [SECURITY.md](SECURITY.md).
